# 星间驿站

星间驿站（AstralStation）是一个面向个人使用的 Windows 游戏工具集合，仅提供简体中文界面。

## 开发目标

首个版本为 Alpha 1.0，采用 C# 与 WinUI，发布为自包含单文件应用，不以常驻运行为前提。

首个模块为「启动管理」：将 StartupSv2 的全部功能与行为重写为 C#，重新组织任务、配置、日历及相关操作的界面布局。后续功能按独立模块扩展，统一使用 C# 维护。

## 当前状态

已抽离 WinUI 应用壳：标题栏、主题、响应式导航、按需创建页面与模块入口。启动管理行为将在下一阶段接入。

使用 .NET SDK 10.0.402 和 Windows SDK 10.0.26100 构建，运行 `./Build.ps1` 发布自包含单文件 `.build/Alpha-1.0/AstralStation.exe`。构建不自动启动应用；界面和功能需实际使用确认。
