# 星间驿站

私人 Windows 游戏工具箱，C# / WinUI，简体中文。当前版本 **Alpha 2.0.1**，暂不添加许可证。

## 构建与运行

需要 .NET SDK 10.0.402 与 Windows SDK 10.0.26100。运行 `./Build.ps1`，生成自包含单文件：

`.build/Alpha-2.0.1/AstralStation.exe`

Windows x64，Windows 10 1809 及以上；无需另装 .NET 或 Windows App SDK。

本版仅编译，不启动应用、不执行测试。

## 使用

- 今日队列：按任务顺序启动、等待、监测与记录，可暂停、重试或手动标记完成。
- 任务库：添加、编辑、排序、安装检测；所有任务均参加队列。支持程序、快捷方式与脚本。
- 运行日历：按各任务的每日重置时间归档。退出工具箱不会结束游戏。
- 设置：主题、托盘、登录启动，以及固定的 960×540、1440×810、1920×1080、2880×1620 窗口档位；界面统一缩放，不支持自由调整大小和最大化。
- 同一数据目录只运行一个实例。新版接管旧版，同版或旧版再次打开时聚焦已有窗口。

自动检测仅覆盖指定游戏清单，跳过 Steam、模拟器和终末地；碧蓝航线暂未加入。安装信息或启动入口不足时可能漏检，可手动添加。默认本地 04:00 重置，可在任务库修改。

数据保存在 `%LOCALAPPDATA%\AstralStation\Launch`，包含任务、设置、完成状态和历史 JSON，以及 `.bak` 备份。`--paused` 暂停启动，`--data-dir "路径"` 指定独立数据目录，`--background` 在开启托盘时后台启动。

## 开发

`App/Launch` 放启动管理功能，`App/Services` 放复用控件与桌面能力。相同功能在原文件扩展，避免重复实现和仅为新增逻辑拆文件；不再新增 Markdown 文档。
