# 星间驿站

星间驿站（AstralStation）是一个面向个人使用的 Windows 游戏工具集合，仅提供简体中文界面。当前版本 **Alpha 1.1**（`1.0.0-alpha.2`）。

## 开发目标

采用 C# 与 WinUI，发布为自包含单文件应用，不以常驻运行为前提。

首个模块为「启动管理」：将 StartupSv2 的全部功能与行为重写为 C#，重新组织任务、配置、日历及相关操作的界面布局。后续功能按独立模块扩展，统一使用 C# 维护。

## 当前状态

已抽离 WinUI 应用壳并接入 C# 重写的启动管理模块，不依赖旧版本可执行文件或 C++ DLL。

使用 .NET SDK 10.0.402 和 Windows SDK 10.0.26100 构建，运行 `./Build.ps1` 发布自包含单文件 `.build/Alpha-1.1/AstralStation.exe`。构建不自动启动应用；界面和功能需实际使用确认。

本仓库为私人仓库，暂不添加许可证。

## 功能布局

| 位置 | 内容 |
| --- | --- |
| 今日队列 | 当前周期进度、暂停/恢复、手动启动、重试、全部重置、近 24 小时活动。 |
| 任务库 | 添加、编辑、复制、停用、排序、启动选项、安装检测和右键操作。 |
| 运行日历 | 按重置周期归档的启动与退出时间、历史快照、复制记录与打开目录。 |
| 模块设置 | 完成后退出、托盘行为、登录启动及数据目录。 |
| 应用设置 | 跟随系统、浅色和深色主题。 |

Windows x64、Windows 10 1809 及以上。发布自包含单文件，不需要另行安装 .NET 或 Windows App SDK。不包含米游数据、登录或 WebView2。托盘和 Windows 登录启动默认关闭，退出应用不结束正常启动的游戏。

## 任务操作

支持 EXE、快捷方式、BAT、CMD、PowerShell 脚本，可手动选择或拖入文件（每次最多 16 个）。监测进程用分号分隔，不区分大小写和 `.exe` 后缀。识别会临时启动目标，最多观察 15 秒并清理本次发现的新进程；原有 PID 不参与清理，通过同一进程句柄复核创建时间防止 PID 复用误杀。识别不携带任务额外启动参数，取消或关闭编辑框会等待清理结束。

任务选项包含自动启用、参数、工作目录、启动前等待（0–3600 秒，默认 30）、检测超时（1–600 秒，默认 15）。工作目录留空使用目标所在目录。PowerShell 使用系统 Windows PowerShell，参数追加在脚本路径之后，执行策略仅对本次进程生效。

推荐检测支持原神、原神国际服、星穹铁道、绝区零、崩坏3、明日方舟原生 PC。终末地暂时移出自动检测，不删除已有任务。国内原神显示为“原神”，推荐结果展示完整路径。检查常用目录、注册表、配置及有限范围的快捷方式，不扫描整块磁盘，不执行快捷方式。找到真实游戏 EXE 才提供添加，隐藏已添加路径；预设重置为本地 04:00，不自动换算海外服务器时区。

任务库选中任务后显示图标操作栏，悬浮提示提供操作名称及快捷键；清除选择后隐藏。今日队列同样仅在选中后显示“启动此任务、重试此任务、此任务标注为完成、重置全部任务进度”。任务库可拖动排序或使用上移/下移。复制产生新 ID 且默认停用。右键保留全部任务操作。

| 快捷键 | 操作 |
| --- | --- |
| Enter / 双击 | 队列启动，任务库编辑；启动前确认，默认取消。 |
| F2 / Ctrl+E | 编辑 / 启动选项。 |
| Ctrl+D / Ctrl+C | 复制任务 / 复制路径。 |
| Ctrl+↑ / Ctrl+↓ | 调整顺序。 |
| Delete / Esc | 删除 / 清除选择。 |
| 菜单键 / Shift+F10 | 打开所选任务或记录的菜单。 |

## 调度规则

自动队列按启用任务顺序执行，检测到任意配置进程才完成；全部匹配进程退出并保存结束时间后继续下一项。手动启动可并行，停用任务仍可手动运行。普通监测按进程名匹配，不区分同名程序路径。

暂停冻结启动前等待，已发起任务继续监测。进入任务库、编辑、确认、文件选择和菜单期间保护交互。启动失败或检测超时只在本会话当前周期跳过，可手动重试。每日完成状态按各任务的本地重置时间计算。

清除完成或全部重置后暂停队列，旧运行不会立即恢复当前周期完成状态；新周期或明确手动启动/重试可恢复检测。手动标记不生成历史，跳过不算完成。删除或更换目标后，旧运行独立保存历史，不给新目标写完成状态。

检测到进程后最小化，开启托盘时隐藏。最多等待 15 秒寻找目标主窗口，只尝试一次聚焦，尊重 Windows 前台限制；手动恢复取消待执行的聚焦。并行任务全部退出后恢复窗口，满足自动关闭时保持最小化等待倒计时。

自动关闭仅在今日队列生效：全部启用任务完成、所有自动/手动/独立监测结束且历史保存成功后等待 15 秒。可见时显示“保持打开”，Enter/Esc 可取消；隐藏时静默等待相同时间。当天已完成时重新打开也保留倒计时。空列表、全部停用、保存失败和交互期间不退出。

登录启动管理当前用户及当前数据目录的独立启动项，不强制启用托盘，移动 EXE 后需重新开启。相同数据目录仅一个实例，再次打开恢复已有窗口。

## 本地数据与日历

默认目录为 `%LOCALAPPDATA%\AstralStation\Launch`，不自动读取或改变旧版数据。

| 文件 | 用途 |
| --- | --- |
| `config.json` | `SchemaVersion: 1` 和任务数组，兼容 V2 字段及缺省值。 |
| `state.json` | 任务 ID 对应重置周期日期。 |
| `settings.json` | 主题、自动关闭与托盘设置。 |
| `History/YYYY-MM-DD.json` | 启动时名称、路径、真实时间、重置时间快照，退出后补写结束时间。 |
| `runtime.log`、`runtime.previous.log` | 活动日志，界面显示近 24 小时。 |
| `crash.log` | 本地未处理异常诊断。 |

JSON 先写临时文件并刷新，再原子替换，保留 `.bak`。读取失败不覆盖原文件。历史坏文件独立报告，不遮蔽其他日期；运行记录保存失败停止调度与自动关闭。

只记录本应用发起且检测到进程的运行，不从旧日志推算，不记录已有进程和临时识别。开始时间取发起调用前，检测超时从调用返回后计时，退出按 500 毫秒轮询观测。重复运行分别保存，跨日/重置退出补写原周期而不拆分。次日标注“次日”，更远日期显示完整日期；缺少结束时间或旧记录缺少重置时间时不显示占位、不推算。

日历使用 WinUI 3 原生 CalendarView，周一开始，仅有记录日期可选，以色条标注记录；左侧日历与右侧详情分为卡片。原生标题和箭头提供年月导航，范围到当前月；底部箭头跳转有记录月份，“回到本月”恢复当前月。日期键盘导航由原生控件处理。历史 Ctrl+C 复制完整记录，Ctrl+Shift+C 复制路径，Enter 打开目录。

```powershell
./.build/Alpha-1.1/AstralStation.exe --paused --data-dir "E:\SomeFolder\AstralStationData"
```

`--paused` 初始暂停，`--data-dir` 指定独立模块数据目录，`--background` 在已开启托盘时隐藏启动。
