# 星间驿站

私人 Windows 游戏工具箱，C# / WinUI，简体中文。当前版本 **Alpha 3.7**，暂不添加许可证。

## 构建与运行

需要 .NET SDK 10.0.402 与 Windows SDK 10.0.26100。运行 `./Build.ps1`，生成自包含单文件：

`.build/Alpha-3.7/AstralStation.exe`

Windows x64，Windows 10 1809 及以上；无需另装 .NET 或 Windows App SDK。



## 使用

- 今日队列：按任务顺序启动、等待、监测与记录；按今日完成状态显示“启动此任务”或“重试此任务”，支持手动标记完成、重置此任务进度，以及右侧的全部重置。
- 任务库：添加、编辑、排序、安装检测；所有任务均参加队列。支持程序、快捷方式与脚本。
- 运行日历：按各任务的每日重置时间归档。退出工具箱不会结束游戏。
- Steam 启动国服：按账号与路径、空EXE占位文件、ACF、Steam 启动选项四步配置终末地，前置步骤未完成时后续整张卡片置灰。支持 Steam 路径检测；进入游戏配置时自动补齐缺失的启动脚本，保留已有脚本。空 EXE 直接生成，显示已有文件的实际大小，已有文件时禁用生成按钮并提供悬浮说明；ACF、整套配置应用和移除前显示具体变更，启动选项仅复制后手动填写。脚本保存在 `%LOCALAPPDATA%\AstralStation\SteamLaunch\4732690`。
- 设置：主题、启动管理设置卡片（完成后行为、托盘、登录启动）及本地数据统一放在总设置。自由调整窗口大小与最大化。最小窗口 800×600 逻辑像素；全界面跟随所在显示器 DPI，窗口变大不再放大控件。
- 同一数据目录只运行一个实例。新版接管旧版，同版或旧版再次打开时聚焦已有窗口。

自动检测仅覆盖指定游戏清单，跳过 Steam、模拟器和终末地；碧蓝航线暂未加入。安装信息或启动入口不足时可能漏检，可手动添加。默认本地 04:00 重置，可在任务库修改。

数据保存在 `%LOCALAPPDATA%\AstralStation\Launch`，包含任务、设置、完成状态和历史 JSON，以及 `.bak` 备份。`--paused` 暂停启动，`--data-dir "路径"` 指定独立数据目录，`--background` 在开启托盘时后台启动。Windows 登录启动会自动携带 `--login-startup` 来源标记。

启用完成后倒计时退出时，本次任务全部完成并退出，或 Windows 登录启动时任务已全部完成，才会在今日队列倒计时 15 秒。任务已完成时手动打开或再次唤起窗口会保持打开；还有运行任务、交互或记录保存失败时不会自动退出。
