# 架构

应用使用 C#、.NET 10 与 WinUI。MainWindow 拥有导航、窗口、主题及应用级关闭策略；模块通过页面工厂按需创建。

首个模块为启动管理。模块的模型、存储、进程服务与调度器不依赖 XAML 页面。应用级生命周期统一管理托盘、单实例、窗口恢复和退出。页面关闭或切换不销毁正在运行的调度服务。

LaunchSession 在 UI 调度器上串行拥有 Store 与 Scheduler。进程快照后台读取，配置/命令变更使旧快照失效；后台线程不操作控件。识别和安装检测支持取消。编辑、文件选择和菜单使用嵌套交互作用域，阻止新自动启动及关闭，已发起监测继续执行。

Scheduler 输出运行事件，MainWindow 处理最小化、恢复和聚焦。自动退出要求全部监测结束、历史保存成功且停留在今日队列；未来模块需要扩展应用级退出条件。

配置与运行快照分离。保存后按 ID 定位，改路径/进程集合将原运行转为独立监测。历史使用启动时名称、路径、时间与周期快照，退出按 ID 补写。

发布入口为 Build.ps1，产物为 .build/Alpha-1.4/AstralStation.exe。构建不自动运行应用，不以构建成功代替实际功能验证。

用户数据不得提交。暂不添加许可证；应用壳样式及图标来自用户指定的旧项目。
